## v0.3 – Data Module

**AI Tool:** ChatGPT  
**AI Usage:** Debugging, Code Explanation, Code Scaffolding, and Code Review.

### Development Focus
- Mengembangkan model data buku.
- Menggunakan local/mock data.
- Menampilkan daftar buku menggunakan ListView.builder.
- Mengimplementasikan Create (tambah buku).
- Mengimplementasikan Read (menampilkan buku).
- Mengimplementasikan Update (mengubah data buku).
- Mengimplementasikan Delete (menghapus buku).
- Menambahkan dialog konfirmasi penghapusan.
- Menambahkan Empty State.
- Menambahkan SnackBar sebagai user feedback.

### AI Contribution

AI digunakan untuk membantu proses pengembangan, antara lain:

1. **Debugging**
   - Membantu mengidentifikasi kesalahan kode.
   - Membantu menganalisis permasalahan pengelolaan data.
   - Memberikan saran perbaikan pada fungsi CRUD.

2. **Code Explanation**
   - Menjelaskan penggunaan List<Task>.
   - Menjelaskan fungsi setState().
   - Menjelaskan penggunaan ListView.builder.
   - Menjelaskan alur pengiriman data menggunakan Navigator.push dan Navigator.pop.

3. **Code Scaffolding**
   - Membantu menyusun struktur awal fitur CRUD.
   - Memberikan contoh implementasi form edit buku.
   - Membantu mengembangkan dialog konfirmasi hapus.
   - Memberikan contoh implementasi Empty State dan SnackBar.

4. **Code Review**
   - Membantu memeriksa struktur kode.
   - Memberikan saran peningkatan validasi jumlah halaman.
   - Membantu memeriksa integrasi form BAB 6 dengan Data Module BAB 7.

5. **Documentation**
   - Membantu menyusun README.md.
   - Membantu menyusun CHANGELOG.md.
   - Membantu menyusun dokumentasi penggunaan AI.

### Developer Responsibility

- Memahami kode yang digunakan.
